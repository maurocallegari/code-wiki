# Tutorial

> Esercizi pratici per imparare il metodo facendo.

---

## Come Usare

Ogni tutorial segue il metodo:
1. **Isola** — capisci cosa non funziona
2. **Definisci** — prompt con formula FILE/TASK/OUTPUT/VINCOLI/VERIFICA
3. **Esegui** — Hermes o Codex
4. **Verifica** — checklist reale
5. **Deploy** — solo dopo verifica
